# 🏛️ Titanium & Emerald Spatial UI Portfolio - Master Architecture

## 1. System Vision & Core Objectives
- **Target Audience:** Corporate Technical Recruiters (3-second scannability) & High-Value Freelance Clients.
- **Design Language:** Titanium & Pastel Emerald (`#11172A` background, glassmorphism, pastel emerald light reflections).
- **Performance Budget:** Locked 60 FPS on mobile/desktop, 100/100 Core Web Vitals, zero client-side battery drain.
- **Cost Target:** 100% Free Tier Infrastructure.

## 2. Locked Technical Decisions (25/25)
1. **Framework:** Next.js 15+ (App Router), React 19, TypeScript (Strict Mode).
2. **Styling:** Tailwind CSS v4, Framer Motion (Spatial Physics), Custom Glassmorphic Primitives.
3. **Background Engine:** Hardware-Accelerated HTML5 Canvas GPU Mesh Engine.
4. **Spatial Physics:** 3D Mouse & Gyroscope Tracking (`prefers-reduced-motion` compliant).
5. **Hero Section:** "Executive Metric" Glass Bar with 1-click Resume CTA.
6. **Project Showcase:** Interactive Bento Grid with In-Place Card Expansion (`layoutId`).
7. **Content Management:** Sanity.io (Headless CMS) for curated Flagship & Client Impact Case Studies.
8. **Automation Engine:** Make.com Webhooks → Sanity.io (Syncing GitHub Repos & LinkedIn updates).
9. **State & Caching:** Zustand + Custom `fetch` hooks (Optimistic UI, Skeletons, lightweight bundle).
10. **Resume & Timeline:** Embedded Glass PDF Viewer + Interactive Node Tree (including Freelance Branch).
11. **Freelance Strategy:** Unified "Client Impact" tags in Bento Grid with production metrics.
12. **Contact Engine:** Next.js Server Actions + Resend API + Zod Validation.
13. **Security:** Upstash Redis (IP Rate Limiting) + Cloudflare Turnstile (Invisible Bot Defense).
14. **CMS Schema:** Strict Block Schema + Optional YouTube Video Embeds.
15. **Social Previews:** Dynamic Edge OpenGraph (`@vercel/og` / Satori).
16. **Analytics:** PostHog Free Tier (Privacy-first event tracking & session replays).
17. **Performance Optimization:** Dynamic Asset Deferral (`next/dynamic`) + Priority Rendering.
18. **Accessibility:** System preference detection (`prefers-reduced-motion`), static mesh fallback, ARIA compliance.
19. **CI/CD:** GitHub Actions (ESLint, Type-check, Jest) + Vercel CLI Deployment.
20. **Domain & DNS:** `is-a.dev` free community domain + Cloudflare DNS.
21. **Email Routing:** Cloudflare Free Email Routing (`hello@akshay.is-a.dev` → Gmail SMTP).
22. **SEO Strategy:** Next.js Metadata API + Dynamic Auto-generated `sitemap.xml`.
23. **Second Brain:** Graphify + Obsidian markdown knowledge graph integration.
24. **Execution Model:** Phased sprint execution with AI coding CLI tool routing.
25. **Repository Strategy:** Git Feature Branches + Pull Requests + Verification Feedback Loops.
